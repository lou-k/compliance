# Compliance

Privacy and data policies for a personal finance tool written and run by one
person for their own household budget. The tool reads bank transactions and
balances through [Plaid](https://plaid.com) into an encrypted database on
hardware the operator owns, and renders a private budget page from it. There
are no other users, no employees and no customers. These documents exist
because Plaid requires them to be published; they describe what the tool does
with the data and how it is kept and deleted.

- [Privacy policy](privacy-policy.md)
- [Data retention and deletion](data-retention-and-deletion.md)

Questions go to the [issues](../../issues) of this repository.
